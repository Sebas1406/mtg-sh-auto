TikTok authorization callback

This page is used as the registered redirect URI for MTG Auto Publisher during TikTok OAuth authorization.

When the production integration is connected, TikTok will redirect the user back to this URL with an authorization code. The backend application will then exchange that code for an access token.

Registered callback URL: https://mtgsh.netlify.app/tiktok-callback.html
