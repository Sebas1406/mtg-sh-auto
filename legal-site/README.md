# Legal Site

Sitio estatico minimo para obtener las URLs que TikTok pide:

- `index.html`
- `terms.html`
- `privacy.html`

## Opcion mas rapida para publicarlo

1. Abre [Netlify Drop](https://app.netlify.com/drop).
2. Arrastra la carpeta `legal-site`.
3. Espera a que genere una URL publica.
4. Usa estas rutas en TikTok:
   - `https://tu-sitio.netlify.app/terms.html`
   - `https://tu-sitio.netlify.app/privacy.html`
